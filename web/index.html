01 — The problem

Agents are powerful.
Keys are dangerous.

Give an AI a wallet key and it can move funds forever. Prompt injection, bad tools, or a compromised agent shouldn’t empty your savings. Stashway keeps the money in a vault the agent can use — but never own.

02 — How it works

Three layers.
One leash.

01

Vault + policy

Caps, allowlist, and freeze live on NEAR. The owner sets the rules; the agent never holds a master key.

02

Counterparty Guard

Every transfer is scored ALLOW / WARN / BLOCK with evidence. New receivers need your OK.

03

Signed permit

Only a Guard-signed permit unlocks agent_transfer. Tamper, replay, or skip it — the chain refuses.

03 — What stops attacks

Built for the ways
agents fail.

Prompt injection

Jailbreak text can’t mint a permit. No permit → on-chain reject.

Intent swap

Changing the receiver after signing fails signature check.

Replay

Used nonces are dead. Same permit twice doesn’t pay twice.

First-time receiver

WARN → you confirm before funds move. Trust is earned.

04 — FAQ

Short answers.
No fine print.

Does the AI authorize transfers?+

No. Guard is deterministic signals + your policy. AI can propose; the leash decides.

What key does the agent get?+

A function-call key limited to agent_transfer — not full access to the vault.

What does Panic do?+

Deletes the agent key on-chain and freezes transfers so nothing else can leave.

Is this mainnet?+

NEAR testnet for the hackathon. Same leash design ports to mainnet later.
